FELIX // ROVER SYSTEM

01. SYSTEM OVERVIEW

FELIX is an autonomous archaeological rover engineered for non-destructive subsurface mapping and surface feature detection.

Equipped with multi-modal sensors to generate high-resolution spatial datasets in challenging terrain environments.

02. LiDAR SCANNING

2D planar laser sensing constructs real-time point-cloud representations of micro-topography and structural remains.

03. COMPUTER VISION

Integrated high-resolution imagery filtered via OpenCV pipelines for edge tracking, photogrammetry, and visual odometry.

04. WENNER ARRAY ERT

Subsurface Electrical Resistivity Tomography via a 4-electrode array layout measuring ground impedance profiles.
